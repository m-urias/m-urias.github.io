# Tools for Economics Research

As an economics student, managing literature, data, notes, code, and version control can quickly become overwhelming. This page gives you an **overview of the core tools** I recommend and links to detailed, step-by-step guides tailored for beginners in economic research (from reading your first academic papers to writing literature reviews and running empirical analyses).

These tools are free, open-source where possible, and integrate well together. Start with Zotero for references, then layer on the rest as needed.

## Overview of Recommended Tools

| Tool          | Purpose                              | Why It Helps Economics Students                  | Link to Guide |
|---------------|--------------------------------------|--------------------------------------------------|---------------|
| **Zotero**   | Reference management & PDF annotation | Automatically imports papers from RePEc/SSRN/Google Scholar, stores your highlights/notes, and generates perfect bibliographies | [Zotero Best Practices](/path-to-zotero-guide) |
| **Obsidian** | Networked note-taking                | Turn Zotero annotations into connected knowledge graphs; link concepts across papers (e.g., IV strategies, minimum wage studies) | [Coming soon] |
| **Python**   | Data cleaning, analysis & visualization | Reproduce empirical results, scrape data, or analyze your own Zotero library bibliometrically | [Python for Econ Research] |
| **GitHub**   | Version control & collaboration      | Track changes to your code, LaTeX papers, and research projects; share with co-authors or advisors | [GitHub for Students] |
| **AI Tools** (e.g., Grok, Claude, ChatGPT) | Literature synthesis & coding help   | Summarize papers, debug Python scripts, brainstorm identification strategies | [Using AI in Economics Research] |

## Getting Started Action Plan
1. Install **Zotero** today and add your first 10 class readings.
2. Create collections and tags that match your courses/topics (e.g., “Labor Economics”, “RDD”, “For Thesis”).
3. Read one paper using the annotation template from the Zotero guide.
4. Come back here as you add more tools to your toolkit.
